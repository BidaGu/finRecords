# Finance Records 财务记录

用于记录账户、收入、支出、转账、信用卡账单与投资的本地工具。应用版本1.2.0。

[打开工具](https://bidagu.github.io/finRecords/) · [English](README.md)

## 开始使用

1. 在线打开工具，或从仓库下载 `Finance Records.html` / `index.html`，用现代浏览器打开。两份HTML包含相同工具，无需安装。
2. 在页首选择 **简体中文**。浏览器会记住语言；语言不会改变财务数据或币种。
3. 选择 **新建文件**，指定美元或人民币；也可用 **打开JSON** 继续已有记录。一个文件内的全部账户使用同一币种，创建后不能直接更换。
4. 在 **账户与资产** 中添加账户。账户从零开始，余额由录入的收支和转账形成。
5. 在 **收入与支出** 中建立分类、添加条目。账户之间转账以及信用卡还款使用 **转账**；信用卡消费记录为支出。

可下载虚构的[美元示例JSON](https://github.com/BidaGu/finRecords/blob/HEAD/examples/demo-recording-3-years-800.json)或[人民币示例JSON](https://github.com/BidaGu/finRecords/blob/HEAD/examples/demo-recording-cny.json)，再用打开JSON载入。示例不含真实财务数据。

金额数值不带币种前缀；项目标题、输入标签、表头和图表中标明 **USD** 或 **CNY**。金额保留千位分组与两位小数，每股价格等高精度数值保留原有精度。

活动日期表示收支发生时间；入账日期用于计算账户余额。已有美元JSON继续受支持，JSON格式版本保持1.0.0。切换语言或选择计算器币种不会执行汇率换算。请先结束对话框、文件操作或预设导入，再切换语言。

## 保存与备份

选择 **保存** 将记录存为JSON，并在私密位置保留文件与备份。下次用打开JSON继续。保存条目只会更新当前页面；关闭或刷新前仍需保存JSON，财务记录不会自动保存。

显示 **已下载副本** 时，请确认文件确实下载成功。JSON保留完整可编辑记录；CSV仅用于表格核对。个人数据请与应用文件分开存放。

## 分析与计算器

**分析 → 账户与资产** 按所选账户和统一入账截止日期统计已记录资产与负债。**分析 → 收入与支出** 分析已勾选条目在活动日期范围内的总额、趋势和分类分布。分析不修改记录，投资按已记录成本统计。

**计算器** 提供复利增长、平均成本和多笔持仓卖出损益，均独立于财务记录，默认使用美元。每个计算器可单独选择人民币。更换计算币种保留输入数值、清除旧结果，并需重新计算；不会进行汇率换算。卖出损益中，每笔持仓的 **全部保留** 可把卖出股数设为0。

每个计算器可保存一个输入预设，并用加载/清除管理；也可导出/导入单独的预设JSON作为备份。预设不包含计算结果或财务记录。旧预设未写币种时按美元处理；计算器重置以及成功新建/打开文件会恢复默认输入，但保留已保存的预设。
